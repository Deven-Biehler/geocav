# GMCAV - a webtool for Geospatial and Molecular Cancer Analytics and Visualization

GMCAV is a publicly accessible web-based cancer informatics tool that enables exploratory analysis across geospatial, molecular, and network-based modules within a single environment. The tool is available at https://gmcav.eecs.wsu.edu/ 

User manuals in the repo provide details to get started with the tool. Additionally, there is a demo video at https://drive.google.com/file/d/12cdgkHEs9pLEERbgWJYQxfMAT90YsvPN/view
